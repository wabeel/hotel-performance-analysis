# Hotel Booking Analysis — SQL & Power BI

## Sobre o projeto

Projeto de análise de dados de reservas de hotéis, desenvolvido para praticar SQL, Power BI e explorar indicadores de desempenho dos Hotéis.

O dashboard apresenta informações sobre receita, reservas, diárias médias, hóspedes e demandas por estacionamento.

## Perguntas respondidas

- Como a receita varia ao longo do tempo?
- Qual tipo de hotel apresenta maior demanda por estacionamento?
- Como a diária média varia entre os meses?
- Como a quantidade de hóspedes varia ao longo do ano?

## Ferramentas

- **SQL:** consulta e combinação de tabelas.
- **Power BI:** criação de indicadores, gráficos e filtros interativos.

## Aprendizados

O projeto permitiu praticar consultas SQL com JOIN e UNION, além da criação de medidas, visualizações e filtro no Power BI.

## Créditos

Projeto desenvolvido com base em um tutorial do YouTube, com adaptações durante a execução devido a diferenças entre a versão utilizada das ferramentas.
